附录 A：mermaid-c vs Visio 差异分析

基于 c4-1.vsdx（mermaid-c 生成）与 Visio 保存后的版本逐字节对比。

一、无需处理的差异

文件差异原因
docProps/thumbnail.emfVisio 新增缩略图纯装饰，Visio 自动生成
_rels/.rels新增 thumbnail 关系配合缩略图，无 thumbnail 时不需要
docProps/app.xmlVisio 扩充元数据（公司、版本号等）不影响功能，Visio 自动填充
docProps/core.xmlVisio 扩充 Dublin Core 元数据同上
docProps/custom.xml属性格式微调已有 RecalcDocument=true，够用
windows.xml窗口坐标/尺寸不同Visio 自动调整到当前屏幕

二、可选处理的差异

文件差异处理建议
document.xml StyleSheetsVisio 扩充了 ~400 个默认 Cell（LockWidth=0, LockHeight=0, ...）不处理：全为 0/false 默认值，Visio 打开后自动补全，程序化生成无意义
masters.xmlVisio 版有 IsCustomNameU/IsCustomName 等属性不处理：不影响 Master 功能

三、需要处理的差异（已全部处理）

文件差异处理
document.xml缺少 SnapExtensions、SnapAngles、Colors、FaceNames✅ 已添加
visio/pages/_rels/page1.xml.rels页面级关系文件缺失⚠️ 当前页面无 Master 引用时不需要

四、StyleSheet 差异详情（不处理的原因）

Visio 在 StyleSheet ID="0"、"3"、"4" 中填充了大量默认 Cell，例如：

LineWeightTrans=0, FillForegndTrans=0, LockWidth=0, LockHeight=0,
LockMoveX=0, LockRotate=0, NoObjHandles=0, HideText=0, ...

这些 Cell 全部为默认值（0 / false），Visio 打开未包含这些 Cell 的文件时会自动使用内置默认值。在生成代码中逐一手动添加毫无意义——只是将文件从 8KB 增大到 17KB，没有任何行为变化。
