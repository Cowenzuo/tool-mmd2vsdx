7. Shape 元素结构

Shape 属性

属性示例说明
ID"5"页面内唯一 Shape ID（数字字符串）
Type"Shape"固定值 "Shape"（Group/Guide/Foreign 也有）
Master"4"引用的母版 ID（有则从母版继承）
NameU"Dynamic connector"通用名称
Name"Dynamic connector"本地化名称
LineStyle"3"线条样式 ID（引用 StyleSheet）
FillStyle"3"填充样式 ID
TextStyle"3"文本样式 ID

有 Master 的 Shape vs 无 Master 的 Shape

特征有 Master（如连接器）无 Master（本地 Geometry）
属性最少：ID, Type, MasterID, Type, NameU, Name, Style IDs 等
Cell 设置仅覆盖值，其余 F="Inh"需设置全部 Cell
Geometry页面覆盖（3 LineTo）完整本地定义
大小~1700 chars~2600 chars
