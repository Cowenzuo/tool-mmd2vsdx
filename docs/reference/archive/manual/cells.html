9. Cell / Section / Row 参考

Cell 属性

属性必须说明
N✔Cell 名称（如 "PinX", "Width"）
V✔值（数值或字符串）
U单位（"IN", "PT", "MM", "DEG", "STR", "BOOL"）
F公式（如 "GUARD(EndX-BeginX)", "Inh", "Width*0.5"）
E错误信息（通常不设）

常见单位

单位含义使用场景
IN英寸位置、尺寸
PT磅 (1/72 英寸)线宽、字号
MM毫米母版页面尺寸
DEG度角度
STR字符串User.Value
BOOL布尔锁定标志等

常用 Cell 清单

Cell典型值说明
PinX / PinYV=数值 U=IN形状中心位置
Width / HeightV=数值 U=IN宽高
LocPinX / LocPinYV=Width*0.5本地坐标系原点
BeginX / BeginYV=数值 U=IN1-D 起点（连接器）
EndX / EndYV=数值 U=IN1-D 终点（连接器）
AngleV=0 F=GUARD(0DA)旋转角度
FlipX / FlipYV=0 F=GUARD(FALSE)翻转
LineWeightV=0.0069 U=PT线宽（0.5pt）
LineColorV="#000000"线条颜色 #RRGGBB
LinePatternV=1线型（1=实线, 2=虚线）
FillForegndV="#FFFFFF"填充前景色
FillPatternV=1填充模式
BeginArrow / EndArrowV=0/4/13/30箭头样式
ObjTypeV=21-D(2) vs 2-D(1)
LayerMemberV=0图层归属
ResizeModeV=0调整模式

Section 类型

Section N说明
Geometry几何路径（MoveTo, LineTo, Ellipse 等 Row）
Character文本字符格式（Color, Size 等）
Paragraph段落格式（HorzAlign 等）
Connection连接点（X, Y, DirX, DirY）
Control控制柄（如 TextPosition 黄点）
User用户自定义数据（如 MermaidId）
