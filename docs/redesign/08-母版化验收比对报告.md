## 2. 逻辑不相符 / 已知近似清单（逐项，均已在代码注释或方案声明）

| # | 项 | 官方（模板/样本） | 本实现 | 性质 |
| --- | --- | --- | --- | --- |
| K1 | 文本度量缓存 | 官方实例缓存 = TEXTWIDTH/TEXTHEIGHT 精确值（字体度量） | 本实现为字符数估算（estW/固定值）；**打开后由公式重算修正**（RecalcDocument=true，F=Inh 继承母版公式） | 近似（不可离线复现；已声明） |
| K2 | class 关系线端式 | 官方样本混合：Dependency/IR=双端 PAR；Inheritance=Begin PAR+End `_WALKGLUE`+`ConFixedCode=5`（几何相关） | 本实现统一双端 PAR 钉接 | 选择官方已验证模式之一；钉接语义与原样本一致，重算收敛；已声明 |
| K3 | 关系线方向 | 官方样本含水平/垂直/斜线段（端口 X1/X2/X3/X4 按几何取） | 本实现统一"下→上"（X3→X4）端口语义 | 端口语义一致，几何随本实现布局；已声明 |
| K4 | ER 关系名 | 官方样本实例**无** RelationshipName/Identifying 行（专篇旧描述与样本不符——以样本为准修订认知） | 关系名走 `<Text>`（官方一维线文本承载） | 与样本一致；专篇认知已修订 |
| K5 | ER 属性行 `DEPENDSON` 首参 | 官方样本首参=5（容器子形状含义未核） | 首参=容器末嵌套子形状 ID（与 class 同源规则） | 待核清单（首参含义未证） |
| K6 | gantt Column 日期列 | 官方样本 6 枚 Column（55/61 字段类型、日期列集合语义未核） | 本实现仅 ID 列（IsID=1，FieldType=55） | 待核清单（日期列语义需新样本） |
| K7 | gantt GUID/数据 | 官方 GUID 由 Visio 生成、数据来自图表模型 | UUID 生成（官方逻辑允许任意唯一 GUID） | 等价 |
| K8 | gantt 日历 | 官方样本固定值（14 天/6 周） | 按 mermaid 数据自动计算（月段/日格/周末连续段） | 机制一致 |
| K9 | gantt Link lines `Sheet.N` 引用 | 官方引用原图 frame=1/row=25 等 | 本实现引用文档内实际 id（frame=1 恒定） | 等价（文档内引用） |
| K10 | sequence 生命线程升步进 | 官方行距 6.35mm（母版 IF/MODULUS）；实例 Y 缓存序列步 0.25mm | 实例缓存按官方序列形态（-3.75 起 0.25 步进、未用段 -6.35 封顶），行序号从 IX14 起 | 缓存形态与样本一致；行距语义列入待核 |
| K11 | sequence note/alt | 官方素材无对应母版 | 显式警告+跳过（待核清单） | 准则 3（不自定义） |
| K12 | class 构造型标记 | 官方仅 interface（`<<interface>>` 对应 Interface 母版） | 其它标记按普通类盒渲染+警告 | 待核（素材缺口） |
| K13 | class 关系语义 | 官方 3 类（继承/实现/依赖）素材 | mermaid 聚合/组合/关联 → unsupported 显式暴露（样本 03 的 `--o`/`-->` 共 3 条：警告+待核） | 准则 3（不映射不自定义） |

> 待核清单汇总：K5/K6/K10（及 mindmap——无素材包，未实施，见方案 07 §2.5）。
