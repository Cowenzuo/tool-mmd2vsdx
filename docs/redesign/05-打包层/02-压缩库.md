# squeeze（⑭ 压缩库）

## 1. 模块职能

squeeze 是管线末段：契约 B → .vsdx 字节。它只懂 OPC/ZIP：部件名 →
条目、Content_Types 与关系表落盘、确定性 zip 参数（DOS 时间 0、deflate
参数固定）。OPC/ZIP 底层是自研的 opc 包（条目/部件 URI/关系表/登记表），
本包做"部件语义 → 条目 + 打包"的最后一层。

## 2. 目录与文件

```
src/squeeze/
├── index.ts        Squeeze.pack(b: 契约B, opts?) → Buffer
├── entries.ts      部件 → zip 条目（名称规范化、目录关系表生成）
└── utf8.ts         XML 文本编码（UTF-8、无 BOM，产物确定）
```

## 3. 类与职责

| 类 | 职责 | 关键方法 |
| --- | --- | --- |
| Squeeze | 门面：契约 B → Buffer | `pack(b): Buffer` |
| EntryMapper | 部件 → 条目 | `map(b): Entry[]` |

## 4. 关键函数表

| 函数名 | 输入 | 输出 | 作用描述 |
| --- | --- | --- | --- |
| pack | 契约 B | Buffer | 校验 → 条目 → zip → 字节 |
| toZipEntries | 部件集 | 条目数组 | uri 去前导斜杠、目录条目生成 |
| deterministicTimes() | — | 时间常量 | DOS 时间恒 0（确定性产物前提） |
| lookupContentType(uri) | uri | 媒体类型 | 与契约 B contentType 核对 |

## 5. 边界与注意

- 本包不解析 XML 语义：契约 B 的部件只是字节原料 + 登记表来源；
- 包内私有：zipArchive 底层留在 opcpkg，两者靠现门面衔接，不跨层；
- 待核：thumbnail 部件是否生成走 xml-parts 决策，本包只负责打包。
