# diag/common（② 通用包：flowchart / block）

> 支持范围（2026-09 收敛）：本包只服务 flowchart 与 block；state/c4 已随图型收敛移除。

## 1. 模块职能

通用包处理扁平图：flowchart、block。它们共用同一套"节点 +
边 + 簇"语义：节点按形状分发到对应几何与母版，边按箭头/样式选择粘附
方式与箭头编码。它也是其它图型包的参照实现：先它打通"契约A→契约B"整条线。

## 2. 目录与文件

```
source/diag/common/
├── index.ts            CommonRenderer.render(a) → 契约B
├── shape.ts            节点写手（形状分发、几何、样式覆盖、文本）
├── edge.ts             连接线写手（端点粘附、箭头、触发器、Connects）
├── cluster.ts          子图簇写手（簇框 + 底色）
└── parts.ts            页面部件组装（pages.xml/pageN.xml/rels）
```

## 3. 类与职责

| 类 | 职责 | 关键方法 |
| --- | --- | --- |
| CommonRenderer | 编排：分派形状与边、组装页面部件 | `render(a): ContractB` |
| ShapeWriter | 形状写手 | `write(shape): XmlNode` |
| EdgeWriter | 连接线写手 | `write(edge): {shape, connect}` |
| ClusterWriter | 子图簇 | `write(cluster)` |
| PartsBuilder | 页面部件组装 | `build(page, shapes): XmlPart[]` |

## 4. 关键函数表

| 函数名 | 输入 | 输出 | 作用描述 |
| --- | --- | --- | --- |
| shapeKindToMaster(kind) | 节点形状 | 母版 NameU | rect→Rectangle、roundRect→Rounded Rectangle、diamond→Diamond、circle→Circle、ellipse→Ellipse |
| writeShapeCells(shape) | 节点 | cell 表 | Pin/W/H/LocPin/样式覆盖（写实例值，最小式与自足式二选一由配置控制） |
| writeShapeText(shape) | 节点 | Text 子树 | 单 run 字面文本，多行用换行 |
| pickPort(edge, side) | 边 + 端点侧 | PortIntent | 端口策略：默认右/左中点，走粘附规则 |
| writeEdgeGlue(edge) | 边 | 公式 + Connects 记录 | PAR(PNT(...))/WALKGLUE + ToPart=100+IX |
| arrowValue(kind) | 箭头类型 | 数值 | 按事件表映射：none/arrow/circle/openarrow |
| resolveStyleClass(node) | 节点 | 样式 KEY | classDef 对应写 FillForegnd/LineColor 覆盖 |

## 5. 边界与注意

- 通用包只做扁平图，不做容器/成员（那是 class/ER 包的事）；
- 显示标注（classDef 颜色）走实例单元格覆盖，不建独立样式表；
- 待核：c4 的 `<image xlink:href>` 命名空间修补（xlink 注入）保留在
  shape.ts 的贴图路径，见 archived 坑位清单 2.5。
