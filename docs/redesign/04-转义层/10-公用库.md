# common（⑪ 公用库）

## 1. 模块职能

公用库是九个图型包共享的"零件库"：把 Visio 语义层的通用能力收拢，
不含任何图型判断。内部按八个组划分，组间依赖自上而下：
geometry → cells → formula → text/styles → masters/ports → infra。

## 3. 类与职责

| 类 | 职责 | 关键方法 |
| --- | --- | --- |
| CommonKit | 服务容器：母版、样式、端口、几何的装配入口 | `styles()`、`masters()`、`ports()`、`geometry()` |
| GeometryBuilder | 几何行构造 | `rect(w,h)`、`roundRect(w,h,r)`、`ellipse(w,h)`、`polyline(points)` |
| CellWriter | Cell 三态写手 | `cell(name, v, u?, f?)` |
| FormulaKit | 公式族写手 | `glueBegin(sheet,row)`、`glueEnd(...)`、`setAtRef(ctrl)`、`guard(expr)` |
| StyleRegistry | 样式表模型与生成 | `register(key, spec)`、`buildParts(keys)` |
| MasterAssets | 资产读取与缓存 | `find(nameU)`、`contentsOf(file)` |
| MasterPacker | 母版装配服务 | `buildParts(nameUs): XmlPart[]` |
| MasterNormalizer | 母版规范化 | `normalizeConnector(xml)`、`normalizeLifeline(xml)` |
| PortStrategy | 端口选择 | `pick(shape, point): PortIntent`、`toPart(ix): number` |
| IdAllocator | ID 分配 | `nextId()`、`dupName(base)` |

## 5. 边界与注意

- common 不 import 任何 diag，不含图型分支；图型专用 cell 由对应 diag 包自行书写；
- 母版装配产出"内容原样 + 条目/rels 重排"（依据 research 5.4），原始
  资产 XML 只经 normalize 校验，不重构语义；
- 公式求值器是 MasterPacker 的内部实现细节（重写 V 缓存用），不作为
  公共 API 导出；
- 样式 KEY 清单以基底 7 枚（class/ER/sequence 用各自官方基座）为准；
  gantt pr 家族随图型收敛已移除。
