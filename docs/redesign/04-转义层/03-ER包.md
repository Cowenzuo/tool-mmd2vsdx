# diag/er（④ ER 包）

## 1. 模块职能

ER 包写数据库语义图：实体是列表容器（成员注册 = 主键属性、主键分隔线、
普通属性三枚母版），属性行是 Group 成员（PrimaryKey/Required 等 User 行
区分角色），关系线专用母版（带 Identifying/ShowMulti 语义行）。设计依据
见 `docs/research/ER-结构分析.md`。

## 2. 目录与文件

```
source/diag/er/
├── index.ts        ErRenderer.render(a) → 契约B
├── entity.ts       实体盒写手（容器，主键区）
├── attribute.ts    属性行写手（主键/普通/分隔线）
├── relation.ts     关系线写手
└── parts.ts        页面部件 + 母版需求
```

## 3. 类与职责

| 类 | 职责 | 关键方法 |
| --- | --- | --- |
| ErRenderer | 编排 | `render(model): ContractB` |
| EntityWriter | 实体盒 | `write(entity)` |
| AttributeRowWriter | 属性行 | `write(attr, kind)` |
| ErRelationWriter | 关系线 | `write(relation)` |

## 4. 关键函数表

| 函数名 | 输入 | 输出 | 作用描述 |
| --- | --- | --- | --- |
| pickAttributeMaster(attr) | 属性 | Master 名 | primaryKey → 'Primary Key Attribute'，否则 'Attribute' |
| writeEntityUser(entity) | 实体 | User 行族 | msvShapeCategories、msvSDListItemMaster1..4、msvSDListRequiredCategories |
| writeAttributeUser(attr) | 属性 | User 行族 | AttributeName=SHAPETEXT、PrimaryKey/ForeignKey/Required BOOL |
| pickRelationGlue(rel, end) | 关系 | PortIntent | 端点可钉实体四中点或属性行左右中点 |
| multiplicityCode(m) | mermaid 多重性 | 数值 | ONLY_ONE/ZERO_OR_ONE/ONE_OR_MORE/ZERO_OR_MORE 映射 |

## 5. 边界与注意

- 属性行只有左右两枚连接行，关系端点钉属性行时端口必须按行数容错；
- msvSDList* 行族的写法与 class 包同构，两者各自持有，不从对方导入
  （边界原则：图型包互不依赖，共同部分已下沉 common.ports/formula）；
- 待核：Identifying/ShowMulti 与 mermaid ER 语法的映射表（e-3）。
