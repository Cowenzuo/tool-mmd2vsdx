### 2.3 主数据流与跨模块契约（与 00 §1/§4 一致，已抽查代码验证）

```
.mmd → [snapshot: mermaid@10.9.8 渲染 + extract 提取] → JSON(协议)
     → jsonToDiagram → Diagram → DiagramImporter(resolveType/assemble/buildPage)
     → XmlParts → OpcPackager(pack) → .vsdx
```

契约类型（core，零依赖）：`Diagram`、`CreateOptions`（含 outputScale/margins/useConnectorMaster/diagramType）、
`XmlParts{XmlPart{uri,contentType,xml}}`、`ConvertResult{ok,error,vsdxBase64,diagramType,pageCount}`；
`PageId/ShapeId = uint32`。snapshot JSON 协议字段（实测 main.mjs 返回）：
`{svg, nodes, edges, clusters, diagramType, direction, gantt, git, pie, quadrant, sequence, boundingBox{minX,minY,maxX,maxY}}`。

## 5. 关键工程决策汇总（已定案）

| 决策点 | 定案 | 依据 |
|---|---|---|
| 语言 | TypeScript（strict） | ts-port 系列既定方向；类型即契约（协议层收益最大） |
| 包结构 | 单包，非 monorepo | 03 §4；规模 ~1 万行 |
| 模块系统 | ESM（type: module） | 与 .mjs 一致 |
| XML | 自研轻量树 + 序列化器 + ~150 行只读解析器 | D17；保序 diff、禁 DTD |
| ZIP | 手写 PKZIP 容器 + node:zlib（raw deflate/inflate + crc32） | D17；确定性、ZipLimits、安全 |
| 数字格式 | formatNumber：语义档 `String(v)`（最短往返）；strict 档（toPrecision(17)+%g 修剪）仅测试用；非有限一律抛错 | 02 §5 语义等价金标准；D4 |
| snapshot 集成 | 进程内直调优先；extract 保持 .mjs；HTTP 模式 P2 | 03/06；01 性能论证 |
| 错误 | 分层：MmdError(4 码)/ZipError(7 码)/内建错误 + [phase] 前缀 | D3 |
| 测试 | vitest 8 套平移；fixtures/golden 提前固化；compare-vsdx.ts 闸门 | 02 TS-800 组 |
| 模具资源 | gen-stencils.ts 生成 stencilData.ts 提交仓库；npm files 排除；prepare-stencils 用户侧；无模具模式兜底 | D14；TS-908 分发红线 |
| 构建/发布 | tsc → dist；bin mmd2vsdx；engines node≥22；npm 包不含模具/不含 chromium | D16 |
| 行为冻结 | mermaid@10.9.8 锁定；提取层能力边界冻结；已知限制（clusters/gitGraph 折线）保持 | 00 §8 |

## 7. 验收与金标准体系

1. **语义等价**（贯穿 M2–M6）：产物与 C++ 基线"结构等价"——部件清单一致、XML 可解析、
   关键 ShapeSheet 数值 ≤1e-9 相对差、格式化文本数值等价（允许最短表达）。
2. **打开性**：golden 开卷测试（M1 起）+ roundtrip（M6）+ Visio 人工打开（M5，用户侧）。
3. **测试全绿**：8 套 vitest（testir/testjson/testparser/testopc/testtranslate/testmasters/
   testroundtrip/teste2e）对应阶段全绿。
4. **性能不倒退**：单图端到端 ≤ C++ ×1.2（实测基线记录于步骤 0 与 M6）。
5. **分发合规**：npm 包不含官方模具与生成资产（TS-908）。

## 8. 风险与对策（摘要）

| 风险 | 对策 |
|---|---|
| XML 序列化行为差异（libxml2 vs 自研） | M1 解析 C++ 部件 → 重序列化等价测试；转义单测（中文/引号/emoji） |
| ZIP 被 Visio 拒绝 | 逐字段对齐（固定 DOS 时戳/无 data descriptor/UTF-8 flag）；golden 开卷 + 7-Zip/Windows 解压 + roundtrip 三重验证 |
| gantt（1,490 行）/masterlibrary（1,487 行）平移误差 | 函数级同名对照、常量/注释保留、每函数对照 C++ 后再样本闸门；保留 C++ 分步注释 |
| 数字格式字节差异 | "语义等价"验收标准；strict 档测试对照；数值 ≤1e-9 |
| connectorBinder 端点行为回归 | 三历史修复 commit 行为测试固化 |
| snapshot 收编行为漂移 | 步骤 0 固化 16 JSON fixtures；M3 前后对比真实渲染 JSON 与 fixtures |
| Playwright/mermaid 升级漂移 | 版本锁定（playwright 主版本 + mermaid 10.9.8）；e2e 金标准兜底 |
| 模具分发合规 | 生成资产不随 npm 包（files 白名单）；prepare-stencils 用户侧；无模具模式兜底（D14） |
| 全流程坑位 | **逐条对照 08 坑位清单**（docs/port-plan/01-坑位清单附录）执行：加载→解析→组 doc→打包 vsdx 各阶段核对后打勾 |
