## 最常踩的几条

1. **用 all-in-one 官方包**，不要用旧图型包，旧包缺线型母版、还带冗余件；
2. **文档基座必须 verbatim 官方 document.xml**（Theme ID6、Connector ID7），
   否则母版样式引用落空，形状变成黑填充；
3. **母版段覆写必须写 `IX='0'`**，否则 Visio 视为新增段，出现双几何段；
4. **单元格 `V` 永远是英寸值**，`U='MM'` 只是显示标签，不参与换算；
5. **实例代数一律逐值对官方样本**：宽高公式、Pin 位置、User 行族、子形状 LocPin；
6. **容器高度与行位按成员实际高度堆叠**，零高的分隔线不占槽位；
7. **页面尺寸要 `DrawingResizeType=2`**，Visio 默认会按打印纸倍数放大页面并平移图形；
8. **审计解析要深度感知**，非贪婪正则在嵌套括号与自闭合形状处会静默截断。

完整条目、数值与证据见 [02-坑位与解法.md](02-坑位与解法.md)。
