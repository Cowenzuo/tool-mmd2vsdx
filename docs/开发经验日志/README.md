## 一句话结论（高频坑）

1. **用 all-in-one 官方包**，不要用旧图型包（缺线型母版/带冗余件）。
2. **文档基座必须 verbatim 官方** `document.xml`（Theme ID6 / Connector ID7），否则母版样式引用落空 → 黑填充。
3. **母版段覆写必须写 `IX='0'`**（Geometry），否则 Visio 视为新增段 → 双几何段。
4. **单元格 V 永远是英寸值**，`U='MM'` 只是显示标签。
5. **一切实例代数逐值对官方样本**（W/H 公式、Pin 位置、User 行族、子形状 LocPin）。
6. **容器高度/行位由成员实际高度堆叠**（零高分隔线不占槽位）；同行实体高度不同时，`top/bottom` 必须取**自身盒**。
7. **本机 Visio COM 可当渲染真值**：打开产物读重算值，能直接判定"Visio 是否重排"。
8. **审计解析要深度感知**：非贪婪正则在嵌套括号/自闭合形状处会静默截断，曾两次误导结论。
9. **母版把文字分在多个子形状上时，实例要"按带"写**：片段标签 = MS6 关键词带（不写即继承「循环」/「选择」）+ MS7 参数带（写 mermaid 标签）；组根 `IsTextEditTarget='0'` 上写文本既居中也无法双击编辑。
10. **"占两格"的构件必须用累计行号**：自消息占 2 格（mermaid 不产出 `self` 类型，靠 `from===to` 判），直接用消息下标会让它与相邻消息压在同一行。
11. **页面尺寸要 `DrawingResizeType=2`**：Visio 默认 `1` 会按打印纸倍数放大页面并整体平移图形，`PageWidth/PageHeight` 形同虚设（实测 11.96×8.01IN 被改成 23.80×11.69IN）。
12. **实例 cell 的 `F='Inh'` 只在"要继承母版公式"时写**：操作数的 `Width` 母版公式依赖 `LISTSHEETREF()`，写 `Inh` 会回退母版默认值（实测四个分支全被摆回默认位置）。
13. **多分支片段 = 容器 + 顶层操作数**：`Alternative fragment` 只有折角标题带 MS6，分支条件由顶层 `Interaction operand` 承载（首条 `NoShow=1`）。
