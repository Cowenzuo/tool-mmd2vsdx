## 1. Visio COM 探针（渲染真值）

用途：打开产物，读取 **Visio 重算后的实际单元格值**，判定"Visio 是否保留/重排"。

> 现成脚本：`docs/开发经验日志/scripts/visio-probe.ps1`（参数 = vsdx 路径）。
> 用法：
> ```powershell
> Copy-Item resources/vsdx-output/04-er-1.vsdx temp/er-render-src.vsdx -Force
> powershell -NoProfile -ExecutionPolicy Bypass -File docs/开发经验日志/scripts/visio-probe.ps1 temp/er-render-src.vsdx
> ```

```powershell
# 核心逻辑（完整版见 scripts/visio-probe.ps1）
$visio = New-Object -ComObject Visio.Application
$visio.Visible = $false
$visio.AlertResponse = 7                                  # 不弹窗
$doc = $visio.Documents.Open($vsdxFull)
$pages = $doc.Pages
$page = $pages.Item(1)                                    # 注意：不要写成 $doc.Pages.Item(1) 链式调用
$shapes = $page.Shapes
for ($i = 1; $i -le $shapes.Count; $i++) {
    $shape = $shapes.Item($i)
    $h = ''; $py = ''
    try { $h = [math]::Round($shape.CellsU('Height').ResultIU, 6) } catch {}
    try { $py = [math]::Round($shape.CellsU('PinY').ResultIU, 6) } catch {}
    Write-Output ("{0,-30} H={1,-10} PinY={2,-10}" -f $shape.NameU, $h, $py)
}
$doc.Close()
$visio.Quit()
```

要点：

- **先复制再打开**：`Copy-Item resources/vsdx-output/<样本>.vsdx temp/er-render-src.vsdx -Force`
  ——直接开产物会锁住文件（后续重新生成报 `EBUSY`）。
- `CellsU('X').ResultIU` 返回**英寸**内部值；`Result("mm")` 可按单位取。
- 需要出图时：`$page.Export("C:\...\out.png")`（**先导出再遍历**，遍历 COM 有时会让
  对象引用失效）。
- 收尾 `$doc.Close()` + `$visio.Quit()`；残留进程：
  `Get-Process VISIO -ErrorAction SilentlyContinue | Stop-Process -Force`。
- 若脚本用 `param()` + `powershell -File` 出现 `$doc` 为 null，改为**脚本内硬编码路径**
  （已在实战中确认可行）。
- **含中文的 .ps1 必须带 UTF-8 BOM**：Windows PowerShell 5.1 对无 BOM 文件按 ANSI
  解码，中文注释会被撕碎并引发 `Unexpected token ')'` 之类的语法错（本轮踩过）。
  补 BOM：
  ```powershell
  $p = (Resolve-Path 'docs/开发经验日志/scripts/visio-probe.ps1').Path
  $c = [System.IO.File]::ReadAllText($p, [System.Text.Encoding]::UTF8)
  [System.IO.File]::WriteAllText($p, $c, (New-Object System.Text.UTF8Encoding($true)))
  ```

## 2. XML 深度感知解析（比正则可靠）

用途：解剖官方实例/产物，取完整 `<Shape>` body（含嵌套子形状）。

```js
// 处理自闭合空形状（<Shape ID="6" MasterShape="6"/>），否则栈会错位
function shapes(xml) {
  const out = []; const stack = [];
  const re = /<Shape\s+ID="(\d+)"([^>]*)>|<\/Shape>/g;
  let m;
  while ((m = re.exec(xml))) {
    if (m[0] === '</Shape>') {
      const t = stack.pop();
      if (t) out.push({ id: t.id, attrs: t.attrs, body: xml.slice(t.start, m.index) });
    } else if (/\/$/.test(m[2])) {
      out.push({ id: m[1], attrs: m[2].slice(0, -1), body: '' });
    } else {
      stack.push({ id: m[1], attrs: m[2], start: re.lastIndex });
    }
  }
  return out;
}
```

要点：

- 官方 XML 常用**单引号**：读入后 `.replace(/'/g, '"')` 再解析（写回产物时不要这样）。
- **别用 `([\s\S]*?)\)\)` 抓成员列表**（嵌套括号截断，见坑位清单 4.1）；
  计数用 `Sheet\.(\d+)!SheetRef`。
- 成员归属用回指确认：`new RegExp('DEPENDSON\\(5,Sheet\\.' + entityId + '!SheetRef')`。

## 3. 模板模块生成（verbatim 官方包）


  条目 `{ masterType, contentXml }`，`contentXml` 为官方 `MasterContents` 原文。

## 5. 未推送提交按大事件合并

```bash
git branch backup/pre-<事件>              # 备份旧历史
git reset --soft origin/master            # 索引保持最终树
git read-tree <组末尾提交>^{tree}          # 每组末态树
git commit -m '<该组提交信息>'
```

- 每组必须是**连续区间**（树 = 该组最后一笔的树），保证内容零变化。
- 验收：`git diff <旧HEAD> HEAD` 为空；`git status` 与合并前一致。
- 详细实践：提交 `3010ea1`…`bc5d31d`（4 笔）。

## 6. 网络绕行：GitHub 直连不可达时推送

```bash
node C:\Users\Public\gh-proxy.cjs          # 本地回环 CONNECT 代理（127.0.0.1:7899）
git -c http.proxy=http://127.0.0.1:7899 push origin master
```

- 原理：把 `github.com:443` 映射到可达的 GitHub 节点（如 `140.82.112.3`），
  保留 Host/SNI，凭据（manager-core）照常工作；**不改 hosts、不改 git 配置**。
- 先探测可用节点：`curl.exe --resolve github.com:443:<ip> -sS -o NUL -w "%{http_code}" https://github.com/`。
