# 01 数据流与主流程

> 配套数据流图 `diagrams/arch-dataflow.mmd`。
> 一条管线：mermaid 文本 → 契约 A → 契约 B → OPC/ZIP 字节。

## 一、主流程（一次 convertText 的旅程）

```
mermaid 文本
   │  ① Parser（source/parser）
   ▼
SnapshotRenderer.render(text)
   ├─ 惰性启动 Chromium；页面注入 mermaid UMD + 提取脚本组（parser/ext/*.mjs）
   ├─ initialize({startOnLoad:false, securityLevel:'loose'}) + 预热
   └─ 串行队列执行；失败重建页面一次
   ▼
快照 JSON（浏览器返回）
   │  ② 归一化（source/parser/normalize/generic.ts，纯函数）
   ▼
契约 A（source/contracts/a.ts）
   │  ③ 分派（source/convert.ts renderContract）
   ▼
diag-* 各图型包 —— 每包 = 契约 A 语义块 → 页面部件（page1.xml）
   │  ④ 组装（source/xml-parts）
   ▼
契约 B（部件清单：uri + contentType + xml）
   │  ⑤ 压缩（source/squeeze）
   ▼
.vsdx 字节
```

`convertText` 由 `Parser.convertText` 返回契约 A；完整转换是
`renderContract`（A→B）+ `PartsAssembler.assemble`（B→完整包）+ `Squeeze.pack`（B→字节）。

## 二、提取策略：DB 优先，SVG 兜底

`parser/ext/bridge.mjs` 先 `getDiagramFromText` 取图型 DB，命中即用语义提取；
否则渲染 SVG 给通用提取器。各图型现状：

| 图型 | 提取器 | 数据来源 |
| --- | --- | --- |
| pie | pie.mjs | DB getSections |
| quadrant | quadrant.mjs | DB getQuadrantData |
| state | state.mjs | DB getRootDocV2 + SVG 盒 |
| git | git.mjs | DB 分支/提交/父链 + 网格布局 |
| sequence | sequence.mjs | DB 参与者/消息/激活/片段 + SVG 盒 |
| mindmap | mindmap.mjs | DB getMindmap 树 + SVG 盒 |
| c4 | c4.mjs | DB 形状/关系/标题（确定性布局） |
| xy | xy.mjs | DB getDrawableElem 柱状单元 |
| class | class.mjs | DB 类/成员/关系 |
| er | er.mjs | DB 实体/属性/关系 |
| gantt | gantt.mjs | 文本直解（DB 对 after 相对日期会抛错） |
| flowchart/state/block/timeline | generic.mjs | SVG g.node / 边路径 |

## 三、转义层契约

- 契约 A：`kind` + `meta` + 通用 `shapes/edges/clusters` + 各图型语义块。
- 契约 B：`parts: XmlPart[]`，`XmlPart = {uri, contentType, xml}`。
- diag 包输出页面部件；`buildPagesXml`（diag-common）产出 pages.xml / pages.xml.rels；
  `convert.ts` 统一前置文档基座（document.xml）与页面。

## 四、运行期装配

`source/parser/renderer.ts` 以 `addScriptTag` 注入 `ext/*.mjs`
（各提取器 + `bridge.mjs` 路由）与 mermaid UMD；浏览器为持久单例，
同一 Chromium 串行复用，`shutdown` 释放。

## 五、开发期资产管线

`resources/visio-binary/stencil-data.json` 由资产脚本生成
（kind → gzip(base64(JSON))，内含 mastersXml/contents/stylesXml/relsXml）；
`source/common/masters/assets.ts` 负责读取解码。黄金样本与 mmd 输入
在 `resources/test-examples/`，由 `source/golden.test.ts` 驱动验收。
