## ① 输入加载（对应 M6/app）
- 【1.1】输出路径二义性 → 以 `.vsdx` 结尾视为文件直接写，否则视为目录写 `outDir/(stem+".vsdx")`。
- 【1.2】批量顺序 → convertDir **串行**、输出序=输入序；FileScanner 只扫顶层 `*.mmd`（大小写敏感、字典序、不递归）。
- 【1.2b】服务形态半空契约（C++ bug：pageCount 恒 1、diagramType 恒空）→ 文档明示"移植可修正"，TS 填真实值。
- 【1.3】中文路径/编码 → TS 天然 UTF-8；注意 Windows 控制台 GBK 代码页，统一 UTF-8 读写。

## ② 渲染提取（对应 M3，extract 保持 .mjs 原样）
- 【2.1】bundle 拼接是硬约束 → 按依赖序拼接单文件自包含脚本、剥 export、不写 import；TS 化必须 IIFE/UMD，**P0 保持 .mjs 拼接零风险**。
- 【2.2】渲染失败降级（gantt 中文等）→ 失败保留空 svg，仍从文本推断类型并解析结构化数据，不阻断。
- 【2.3】图型检测两路径 → 优先 aria-roledescription（去 -v2/-beta），否则文本首行推断；TS 收敛单一 `normalizeDiagramType()`+单测。
- 【2.4】direction 推断 → 节点 translate 坐标范围 xRange>yRange→LR 否则 TB；节点 0/1 个保持默认 TB。
- 【2.5】SVG 命名空间修补 → C4 `<image xlink:href>` 需注入 `xmlns:xlink`，修补必须保留。
- 【2.6】⚠️ 节点 id 规范化（最易踩）→ 只剥**尾部** `-\d+$`（用户 A-1 保留）；边 path id 先剥尾部数字再用已知节点集**最长前缀匹配**；单测覆盖 A-1/连字符/数字后缀。
- 【2.7】标签多选择器兜底 → 依次试 `.nodeLabel/.label text/...` 取首个非空；类图成员行序=label 行序（divider 按 y1 收集），改动=破坏类图。
- 【2.8】形状识别优先级 → polygon→diamond、circle、ellipse、rect rx>0→roundRect、否则 rect；菱形**必须 polygon 判定**。
- 【2.9】parsePathD 两套勿合并 → dom.mjs 版（M/L/C/Q，不支持 A）供 flowchart；git.mjs 版支持 **A 弧线**（12 步采样）供 git 箭头。
- 【2.10】边样式/箭头判定 → style 按 class（dotted/thick）；箭头只看 marker-end（circle→circle）；openarrow 区分不了是**已知边界**（er/class 另处理）。
- 【2.11】cluster 提取 → `.clusters .cluster` bbox；已知限制：cluster 不输出到 VSDX。
- 【2.12】颜色转换 → cssColorToHex 支持 hsl/rgb/#hex；失败返回空串由上层兜底；git 分支色从 `<style>` 正则提取。
- 【2.13】gantt 日期（SVG 无日期）→ Excel 序列日 **UTC 起算 1899-12-30**（`round((UTC(y,m-1,d)-UTC(1899,11,30))/86400000)`）；duration 单位换算；milestone=`duration===0 && !isAfter && 有日期`；`endSerial=floor(maxE)+2`；**TS 用 Date.UTC 勿用本地时区**。
- 【2.14】sequence 提取（实测启发式）→ 移植**一字不改**（actor x±10 匹配、messageLine0/1 轮换按 y 配 messageText、虚线双兜底、x<20px 子段扩展、生命线归一、激活条/片段包围盒）。
- 【2.15】gitGraph 提取 → commit 查 circle+rect 双 class；r<4 装饰小圆过滤、同位置取大圆；标签文本优先作 commit id；箭头端点就近 <400；**线色：merge=子分支色、seq/创建=目标分支色**；bounds 外扩。

## ③ JSON→IR（对应 M0 core 类型 + M2 jsonToDiagram）
- 【3.1】status 门禁 → 顶层必须 ok 否则抛 MermaidError（进程内直调也保留）。
- 【3.2】枚举映射+缺省兜底（错误枚举不能崩）→ shape 未知→Rect、style→Normal、arrowHead 未知→**None**；`value(key,default)` 全兜底；TS union **不能直接 as**，写 Record 查表函数。
- 【3.3】专用子结构按需解析 → gantt/git/pie/quadrant/sequence 各 is_object() 才解析，缺字段跳过；**isAfter 有意丢弃**（milestone 布尔由提取层预计算，渲染器按 dependsOn 重算），勿加回。
- 【3.4】契约漂移静默风险 → SnapshotResult 类型 + 单测锁字段名；运行时守卫只验关键字段（id/x/y），**不收紧提取层**。
- 【3.5】SnapShotNode（提取层）与 IR Node（消费层）**分开定义**，jsonToDiagram 收编。

## ⑦ 连接线（对应 M2 主链；全工程最深的坑，历史修复最多）
> 背景：OLE 快速路径（Word 内嵌双击激活不重算，直接显示存储几何与 V 缓存）vs 直接打开（完整重算）。
> 几何**烘焙为页面差正交折线**、V 与 F 自洽（输出"Visio 保存形态"）、保留完整 1-D 身份 cell。
> **"文字位置是连接线的体温计"**：端点/1-D 变换错→文字错。
- 【7.1】1-D 身份 **13 cell 绝不能删**（2d71c5e→152e8bd 大回归）：Angle=GUARD(0DA)/FlipX/FlipY=GUARD(FALSE)/ResizeMode=0/ObjType=2/GlueType=2/LockHeight=1/LockCalcWH=1/NoAlignBox=1/DynFeedback=2/NoLiveDynamics=1/ShapeSplittable=1/TxtAngle=0；**实例与母版两处都要固化**（Word 二次改写清实例级 → 母版级穿过）。
- 【7.2】⚠️ 端点粘附 → ToPart=100..103（普通形状 X1 左/X2 右/X3 下/X4 上）；**类框=角锚点**（dividers 非空，LocPin=(0,0)）；**菱形 X3=上 X4=下与矩形相反**（9b3591a/2324c28 两次回归）；直线粘整体（ToCell=PinX、ToPart=3），**直角折线必须粘连接点 100..103**；Begin/End=`PAR(PNT(Sheet.N!Connections.Xi,Yi))`；单测覆盖四组合。
- 【7.3】端点公式与 V 自洽 → PinX/PinY=`GUARD((BeginX+EndX)/2)`、Width=`GUARD(EndX-BeginX)`；退化线（W/H=0）→盒 0.2DL（**Word 嵌入会把 Width=0 改写 0.2DL → 生成期就固化 0.2DL 形态**）；+0.1 偏移**必须同样作用于文本**。
- 【7.4】路由属性 → ShapeRouteStyle（1=直角、**mindmap=2 直线**）、ConLineRouteExt=1（6fa0413/7fe3865 从 2 改 1）、ConFixedCode=6；缺则无线型切换 UI。
- 【7.5】烘焙正交折线 → 无独立直线概念（竖段退化 0）；首末出射方向决定四组合；零长顶点剔除（1e-9）；**waypoints 只用于判定出射方向、不作几何顶点（⚠️最易移植错）**；末尾 Del 占位行（防文字自动重摆；遗留风险：多固定 LineTo 后线型切换 UI 可能失效）。
- 【7.6】文字位置公式链（体温计）→ 目标点=**折线中段 p1→p2 中点**（ER=线中点）；TxtPin=目标−TxtLocPin、公式 SETATREF(Controls.TextPosition)；**TxtWidth/TxtHeight GUARD 钉死估算值**（中文 0.14/字、ASCII 0.08/字+0.1 边距、clamp[0.5,4.0]、TxtHeight 固定 0.2000515258789062）；**XDyn/YDyn 必须引用 Controls.TextPosition**；中文估宽 C++ 按 UTF-8 字节/3 → TS 按码点等效复刻。
- 【7.7】线型/箭头 → Dotted→LinePattern=2；Thick→LineWeight=2/72；箭头数值索引：None=0、Arrow=**4**、Circle=**30（空心菱形=聚合，勿改成圆点）**、OpenArrow=**14**（继承/实现）；大小 V=2+THEMEVAL 公式。
- 【7.8】⚠️ EventXFMod 连锁（b39ada3）→ **每个形状（含框）都补 EventXFMod=0**，否则 _XFTRIGGER 引用 #REF! → 文字错位。
- 【7.9】ER crow's foot（Visio 16.0 实测索引）→ `||`=25、`|o`=31、`}|`=28、`}o`=29、无=0；关系线 Type="Group"+Relationship 母版+User.ShowMulti V=0 F=FALSE+User.RelationshipName(U=STR)。
- 【7.10】Connects 段 → **挂页面 `<Connects>`（页面级惰性创建）**；非 ER：BeginX→源(FromPart=9)/EndX→目标(FromPart=12)；ER：ToPart=3 整体粘附；sequence 激活条/消息 ToPart=100/102。

## ⑭ TS 化铁律（跨阶段 10 条）
1. **别"统一"特例**（ER 关系线/lifeline 只写 PinX/PinY/激活条禁 Angle/gantt 固定 A3——每个"不合理"分支都是实测产物）；
2. **常量照抄不优化**（17 位布局常量/cap 表/guidFor/硬编码 V 缓存/TxtHeight——改了产物就漂）；
3. **单位语义三件套**：U 是单位标记（U=MM 的 V 仍英寸）；字符串 cell 必须 U='STR'；数值 U 照抄；
4. **双路径思维**：OLE 快速路径（读缓存）与直接打开（重算）两条路径都必须正确，V 与 F 自洽；
5. **数字格式两套**：母版 V 重写 16 位与 XmlBuilder 17 位分别实现勿混；
6. **Word 嵌入是隐藏验收项**（纯打开正常≠合格，有条件 OLE 复测）；
7. **顺序即协议**（形状 ID/masters.xml 物理序/XmlParts 序/ZIP 条目序全部影响一致性）；
8. **文本估宽按 UTF-8 字节循环是全库约定**（各档位不同，估宽只影响文字框预尺寸）；
9. **V/F/U 铁律**：V 恒英寸内部值；U 仅显示单位；F='Inh'=继承 vs 无 F=本地覆盖——语义完全不同；
10. **软失败与硬失败分界**：求值失败/缺母版→保留原件或 no-op（软）；输入校验/模型错误/validate 不过→抛错中止（硬）；**别把软改硬（崩真实样本），别把硬改软（产坏文件）**。
