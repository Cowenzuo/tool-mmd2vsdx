10. 文本定位与 SETATREF

Visio 连接器文本定位机制

连接器上的文本位置由 三个关联的 Cell 组 协同控制：

Cell位置公式/值作用
TxtPinXShape 顶层F="Inh" (Master: SETATREF(Controls.TextPosition))黄点位置，用户拖动时变化
TxtPinYShape 顶层F="Inh" (Master: SETATREF(Controls.TextPosition.Y))同上（Y 轴）
Control.XControl→TextPosition纯 V 值（无公式）文本实际显示位置
Control.YControl→TextPosition纯 V 值（无公式）同上（Y 轴）
Control.XDynControl→TextPositionF="Inh" (Master: Controls.TextPosition)动态跟踪 Control.X
Control.YDynControl→TextPositionF="Inh" (Master: Controls.TextPosition.Y)同上（Y 轴）

SETATREF 函数

SETATREF(target_cell) 在当前 Cell 上设置一个 单向写回绑定：

  • 当用户通过 UI（拖动黄点）修改当前 Cell 时，自动将新值 写入 target_cell
  • 不是双向绑定：target_cell 变化不会回写到当前 Cell
  • 公式返回值 = 当前 Cell 自身的值

拖动流程

  1. 用户拖动黄点 → UI 修改 TxtPinX/TxtPinY
  2. SETATREF 触发 → 将新值写入 Control.X/Control.Y
  3. Control.X 的公式（如果有）被 SETATREF 覆盖清除
  4. XDyn 的 Controls.TextPosition 公式重新计算 → 等于新的 Control.X
  5. 文本渲染在 Control.X/Y 位置

Visio 默认文本位置规则

场景Control.XControl.YTxtPinXTxtPinY
新建连接器，有文本居中偏右（考虑文字宽度）-0.1875（线上方固定）匹配 Control.X（F=Inh）匹配 Control.Y（F=Inh）
新建连接器，无文本Width/2（中心）-0.1875同 Control同 Control
用户拖动后用户新位置（公式被清除）用户新位置用户新位置（SETATREF 写入）用户新位置

Visio 保存后的 Control 段格式（与新建不同！）

重要发现：Visio 新建连接器时 Control X/Y 没有公式（纯 V 值），但 保存并重新打开后，Visio 会补上比例公式：
<Cell N='TxtPinX' V='0.45' U='IN' F='Inh'/>
<Cell N='TxtPinY' V='0.143' U='IN' F='Inh'/>

<Section N='Control'>
  <Row N='TextPosition'>
    <Cell N='X'    V='0.45'  U='IN' F='Width*0.432'/>    <!-- 有比例公式！ -->
    <Cell N='Y'    V='0.143' U='IN' F='Height*0.583'/>   <!-- 有比例公式！ -->
    <Cell N='XDyn' V='0.45'  U='IN' F='Inh'/>
    <Cell N='YDyn' V='0.143' U='IN' F='Inh'/>
  </Row>
</Section>

✅ 正确方案（mermaid-c 当前实现）

appendCell(position, "X",    safeWidth / 2, "IN", "Width*0.5");
appendCell(position, "Y",    -0.1875,       "IN", "Height*-0.75");
appendCell(position, "XDyn", safeWidth / 2, "IN", "Inh");
appendCell(position, "YDyn", -0.1875,       "IN", "Inh");
实际根因与修复（2026-07-27）：

经过与 Visio 保存文件逐字节对比，发现文本位置异常的真正根因：

  1. Control X/Y 缺少比例公式——没有 Width*0.5/Height*-0.75，文字位置固定不变，线长变化时不能按比例跟随
  2. XDyn/YDyn 缺少 F="Inh"——Master 的 Controls.TextPosition 自引用公式不生效，导致黄点拖动后 Control 段与控制点不同步
  3. TxtPinX/Y 保持 F="Inh"——确保 SETATREF 活跃，黄点拖动可用

修复量仅 4 行代码（给 appendCell 加公式参数）。之前的几十轮迭代误判了根因（反复修改 Geometry、SETATREF 写法、Master 引用等），均未触及 Control 段公式缺失这一核心。

页面实例应设置的 Cell（Fresh Visio Connector 格式）

<Cell N='TxtPinX' V='2.768' F='Inh'/>
<Cell N='TxtPinY' V='-0.1875' F='Inh'/>

<Section N='Control'>
  <Row N='TextPosition'>
    <Cell N='X' V='2.768'/>          <!-- 无 U, 无 F -->
    <Cell N='Y' V='-0.1875'/>        <!-- 无 U, 无 F -->
    <Cell N='XDyn' V='2.768' F='Inh'/>
    <Cell N='YDyn' V='-0.1875' F='Inh'/>
  </Row>
</Section>
