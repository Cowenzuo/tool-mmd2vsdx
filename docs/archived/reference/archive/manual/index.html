VSDX 格式手册 — 总览

本文档基于对 Microsoft Visio 生成的 .vsdx 文件以及 mermaid-c 项目的逆向分析编写。记录了 VSDX 文件的完整结构、各 XML 部件的职责、关键参数及其组织形式。

VSDX 文件本质

VSDX 是一个 ZIP 压缩包，遵循 OPC (Open Packaging Convention) 规范。可以用任何 ZIP 工具解压查看。

ShapeSheet 数据模型

Visio 的每个 Shape 本质是一个 ShapeSheet 电子表格。XML 中的 Cell 对应电子表格的单元格：

  • Cell: 单个属性，含 N(ame)、V(alue)、U(nit)、F(ormula)、E(rror)
  • Section: 一组相关 Cell 的容器（如 Geometry、Character、Control）
  • Row: Section 中的一行（如 Geometry 的一个顶点、Connection 的一个连接点）
  • F="Inh": 从 Master 继承公式
  • F="GUARD(...)": 保护公式不被用户交互覆盖
  • F="SETATREF(...)": 设置"用户修改时回写目标"的绑定
关键原则：有 Master 的 Shape 只需设置 覆盖值（仅 V，或 V+F="Inh"），其余全部从 Master 继承。无 Master 的 Shape 需要本地设置所有 Cell。
