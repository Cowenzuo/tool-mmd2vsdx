1. ZIP/OPC 结构

ZIP 格式要求

参数值说明
压缩方法Store (0) 或 Deflate (8)不支持其他方法
版本2.0 (20)version needed to extract
Flag bit 11UTF-8 文件名现代 ZIP 读取器都支持
Flag bit 3不使用 Data Descriptor预计算 CRC/Size 写入 Local Header
ZIP64不支持拒绝 ZIP64 格式
加密不支持拒绝加密条目
多盘不支持disk=0

条目顺序要求

[Content_Types].xml 必须是第一个条目。OPC 规范要求。

CRC 校验

使用 zlib 的 crc32() 计算 IEEE 802.3 CRC-32。标准实现已经包含最终 XOR 0xFFFFFFFF。

OPC 部件 URI

所有部件路径使用正斜杠 /，相对于包根目录。例如：

visio/pages/page1.xml
visio/masters/master2.xml
docProps/custom.xml

部件命名约定

部件URI 模式

母版索引visio/masters/masters.xml
母版内容visio/masters/masterN.xml
