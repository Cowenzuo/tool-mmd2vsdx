## 第 0 步（N4，开工前置）：增强 compare_gantt.py

现脚本只比 Type/Master 数量 + User/Property 行名集合 + 子形状数，**捕获不到**
大部分改法（F 公式、顶层 Cell 集合、Section 有无、Comment 形式、U 单位）。
必须新增：
1. 顶层 Cell N 集合对比（逐类：框架/列/行/刻度/任务条/里程碑/TE）
2. User 行 **F 公式**对比（Value 单元格的 F，放行清单=v4 §7）
3. Section 名集合对比（User/Property/Control/Connection/Field/Actions）
4. 逐类抽查：Comment 是 Cell 还是属性、U 单位、子形状覆盖清单
5. 输出统一差异报告（类型/数量/Cell/F/Section），每批"差异清零"以此为唯一判据

## A. 框架（P0）

**现状（已核实）**：User 段含 StartDate/EndDate/ScaleUnits/Scalar(已 setUserRowFormula)/
WorkingDays/DayStart/EndTime/PriSecUnitsType/WDLookup/WHLookup/**WTScalar(公式错)**/
**HeaderHeight(多写)**/GUID 锚点；顶层缺 LayerMember=0、LocPinY 无 F=Inh、多写 LocPinX、
缺 Height 前向引用公式。

**改法**：
1. 删 `addVal(user,"HeaderHeight",kHeaderH)`
2. `WTScalar` → `addVal(user,"WTScalar",0.3333333333333333,"DL","Inh")`
3. 补顶层 `setNumericCell(frame.node,"LayerMember",0,"IN")`
4. `LocPinY` 改 F=Inh；**删 LocPinX**（官方无）
5. 行创建完后补 Height：`setNumericCell(frame.node,"Height",chartH,"IN",
   "Sheet.<首行>!PinY+User.HeaderHeight-Sheet.<末行>!PinY+Sheet.<末行>!Height")`
6. 框架 User 行顺序对齐官方（GCVisioGUID 在前）——P2

## B. 列（P1）

**现状**：✅ 列 HeaderHeight(F=框架) 勿删；类型码/链式 PinX/GCPrevColGUID 正确
**改法**：
1. 补 LayerMember=0（系统性前提）
2. 刻度列补 Actions 段（Row_3/Row_4，`Disabled=0 F=Inh`）——P2 可暂缓

## C. 刻度（P0）

**现状（已核实）**：次/主/NWT 的 PinX/PinY/Height 已是 GUARD 公式；
缺 Width LR+RR；次刻度硬编码单块（非自然月）；主刻度写静态 Text（官方无）；
主刻度/NWT 多写 LocPinX；次刻度缺 Field 段与 StartDate F。

**改法**：
1. **三个刻度（含 NWT）Width F 改**：
   `User.ScaledDuration-(User.LeftWidthReduction+User.RightWidthReduction)`
2. **次刻度自然月语义**（v4 §3.3 + 终审 N1）：
   - 遍历覆盖的每个自然月，每月一个；Duration=当月天数、Offset=月起点−图起点（可负）
   - 补 **Field 段**：F=`User.PreText&FORMAT(User.StartDate,INDEX(Sheet.<框架>!
     User.SecScaleUnitsType,Sheet.<框架>!User.SecScaleCellTextFormat))`
   - **User.StartDate F**=`Sheet.<框架>!User.StartDate+User.Offset`
3. **主刻度去 Text 补 Field**：删 `replaceShapeText(tick.node,...)`；补 Field 段
   （F=`User.PreText&FORMAT(User.StartDate,INDEX(...PriScaleCellTextFormat...))`）
4. 主刻度**首例不写 Offset**；主刻度/NWT **删 LocPinX**（N2，仅留 LocPinY F=Inh）
5. 补 LayerMember=0

## D. 行（P1）

**现状（已核实）**：✅ GUID 链/GCPrevRowGUID/HeaderWidth/HeaderPinX 已补
**改法**：
1. **删多写的 Height/LocPinX/LocPinY**（N3：官方行顶层只有
   PinX/PinY/Width/LayerMember/TxtWidth/TxtLocPinX）
2. 首行文本留空（官方无 Text）
3. 补 LayerMember=0

## E. 任务条（P0）

**现状（已核实）**：8 子已建；Property/Control 已有；Width 缺 LR+RR；Comment 是属性
（官方 Cell F=Inh）；缺 Connection；多写 IsSummary/Dependency；DependencyDuration
单位错；子形状缺 LayerMember；MS=5 缺 Width/LocPinX。

**改法**：
1. Width F → `User.ScaledDuration-(User.LeftWidthReduction+User.RightWidthReduction)`
2. **Comment 改 Cell**：setStringCell + F=Inh（官方 `<Cell N='Comment' F='Inh'/>`）
3. **Connection 段**：`appendSection(bar.node,"Connection")`，两 Row `T='Connection'`
   N=LeftSide/RightSide，各**仅 X Cell**（V=0 / V=任务宽，F=Inh）——无 Y
4. **删 IsSummary、Dependency** 实例行（母版固有；仅依赖任务显式写）
5. **DependencyDuration** → `addVal(user,"DependencyDuration",-1.5E300,"MM","Inh")`
6. **User.StartDate/Offset 带官方 F**（见数值语义）
7. 子形状：8 子全补 LayerMember=0；MS=5 补 Width/LocPinX(F=Inh)；
   MS=10/9 只写 LayerMember；MS=11/13 PinX 缓存值对齐官方(0.3673/0.1246,MM)——P2
8. 顶层：**删多写 LocPinY**（官方无）；补 LayerMember=0

## F. 里程碑（P0，新增）

**现状**：IR 有 milestone，render 全走 Task bar
**改法**（v4 §3.10 + 方案终审 F）：
1. 任务循环 `t.milestone ? Milestone : Task bar`（二选一）
2. 顶层：PinY=`Sheet.<行>!PinY`、PinX 同任务条、Width=0、
   **Height F=`Sheet.<行>!Height`**、LayerMember=0、Comment(Cell F=Inh)
3. User：ScaledStartPos/ScaledDuration(F=`IF(IsSummary=1,DependencyDuration,
   Duration×Scalar)`)/StartDate/ScaleStart/ScaleEnd/Offset/ScaledEndPos/WDOffset/
   WHOffset/LastStartFromMove/WTNormalizedStart + **DependencyDuration(F=Inh,MM)** +
   GUID（GCVisioGUID/GCModelGUID/GCChartGUID/GCRowGUID/ParentModelGUID；无 GCColGUID）
4. **不写** Duration/IsSummary/Dependency 实例行
5. Property：同任务条但 **Prop.Duration F=`FORMAT(0,"0.####")&"天"`**
6. **无 Control、无 Connection 段**；8 子覆盖仅 MS=11/12/13 TextLeft/TextRight，
   全补 LayerMember=0
7. ⚠️ **N5：样例需含里程碑任务**（否则 104 类 0 vs 0 无法验证）

## 数值语义（P1，先定规则再实施）

官方实测（任务条 ID=26/40/54/68/82）：
1. **Prop.End**：1 天任务 `End=Start`；多天 `End=Start+日历天数`
   （ID=82: Start=46247.5, End=46251.5, User.Duration=4, Prop.Duration="2天"）
2. **UserDefTime**：恒=图起点+8h（46240.3333）→ `gantt.startSerial + 8/24`
3. **User.StartDate F**：`MAX(Sheet.<框架>!User.StartDate+(User.Dependency-User.
   ScaleStart)/Sheet.<框架>!User.Scalar,User.WTNormalizedStart)`
4. **User.Offset F**：`User.WDOffset+User.WHOffset+User.StartDate-Sheet.<框架>!User.StartDate`
5. **WDOffset/WHOffset/LastStartFromMove/WTNormalizedStart/ActualStart/ActualEnd 的 F**
   ——**待拍板**：补公式（依赖框架母版 WDLookup/WHLookup/WTScalar/WTLookupSep，
   已确认 master1.xml 具备）or 列入有意差异（P1，勿拖到实施中途）
