约定与边界：

- `VSDX解压结构研究` 是唯一事实源，实现与验收都对着它，不对着历史产物；
- `开发过程` 装的是**现役设计**：写当前状态，改了代码就改文档；过程记录不留，
  需要"当初为什么"这类来龙去脉时从 git 历史里翻；
- 素材解压包 `VSDX解压结构研究/标准研究模板-手动创建vsdx并解压/` 有两重身份：
  **对外共研的模板内容标本**（供他人逐文件对照官方 Visio 产物）与
  `tests/master-templates.test.ts` 的夹具（逐字节比对母版固化结果）。
  它**刻意留在仓库**，不是冗余产物，不要当垃圾清理；动它必须同时动测试，
  素材原文也不随之搬进其它文档正文；
- 归档材料不回溯改写：`c4-1/` 是自产样本（第六章对照用），`gantt/` 对应图型
  已移除支持，两者只作研究证据保留；
- 「已讨论、暂不实施」的功能立项集中在 [待讨论功能备忘.md](待讨论功能备忘.md)，
  不散落在各区。
