# 02 数据流与画布

> 现役口径：一次转换的数据怎么流、各类图型从哪里提取、页面尺寸怎么算、
> 母版与样式资产从哪里来。只写当前状态；演进过程与阶段验收快照从 git 历史里查。
>
> 结构分层与各包职责见 [01-结构设计.md](01-结构设计.md)。

## 一、主流程

```
mermaid 文本
   │  ① Parser（source/parser）
   ▼
SnapshotRenderer.render(text)
   ├─ 惰性启动 Chromium；页面注入 mermaid UMD 与提取脚本组（parser/ext/*.mjs）
   ├─ initialize({startOnLoad:false, securityLevel:'loose'}) 并预热
   └─ 串行队列执行；失败重建页面一次
   ▼
快照 JSON（浏览器返回）
   │  ② 归一化（source/parser/normalize/generic.ts，纯函数）
   ▼
契约 A（source/contracts/a.ts）
   │  ③ 分派（source/convert.ts renderContract）
   ▼
diag 各图型包：契约 A 语义块变成页面部件（page1.xml）
   │  ④ 组装（source/xml-parts）
   ▼
契约 B（部件清单：uri、contentType、xml）
   │  ⑤ 压缩（source/squeeze）
   ▼
.vsdx 字节
```

完整转换由三步拼成：`renderContract`（A 到 B）、`PartsAssembler.assemble`
（B 到完整包）、`Squeeze.pack`（B 到字节）；适配层只做编排与回执，不复制这三步。
数据流图见 `diagrams/arch-dataflow.mmd`，分层总览见 `diagrams/arch-overview.mmd`。

## 二、提取策略

先取图型 DB，再退回 SVG：

| 图型 | 提取器 | 数据来源 |
| --- | --- | --- |
| class | class.mjs | DB 类、成员、关系 |
| er | er.mjs | DB 实体、属性、关系 |
| sequence | sequence.mjs | DB 参与者、消息、激活、片段，加 SVG 盒 |
| flowchart / block | generic.mjs | SVG 节点与边路径，快照保留 mermaid 真实图型名 |

其余图型不注入提取器：`getDiagramFromText` 拿到的真实图型名会带回快照，
归一化层据此直接抛"不支持的图型"，不兜底降级。

运行期装配：`parser/renderer.ts` 用 `addScriptTag` 注入 `ext/*.mjs`（各提取器加
`bridge.mjs` 路由）与 mermaid UMD；浏览器是持久单例，同一 Chromium 串行复用，
`shutdown` 释放。

## 三、画布口径

页面尺寸等于内容外包围框加两倍半线宽，`kCanvasMargin = 0.0053IN`；全图型
`DrawingResizeType=2`，禁止 Visio 打开时按打印纸倍数放大页面。内容盒按图型计算：

- flowchart 与 block：形状、边 waypoints、簇的并集；
- class 与 ER：布局实际放置的盒的并集，并把盒整体平移到边距起点；
- sequence：`sequenceContentBox()`，涵盖页眉盒、生命线长度、消息文字、片段与备注，
  渲染器用 `x0` 与 `pageHpx` 做坐标映射。

## 四、资产管线

母版不依赖外部资产文件。flowchart 与 block 用到的 6 枚母版（节点 5 种加
Dynamic connector）原文固化在 `source/common/masters/templates.ts`；class、ER、
sequence 的官方母版（合计 37 枚 MasterContents）固化在
`source/common/masters/templates/` 下按图型分的模块里。二者都从官方模具提取物
一次性生成，与 `docs/VSDX解压结构研究/` 的素材逐字一致。

`source/common/masters/assets.ts` 的 `buildMasterCatalog()` 与 `buildRecord()` 按
NameU 直接构建目录记录，ID 从 100 起，rId 与文件名重写，构建期零文件依赖。
样式基座同样程序化，走 `common/styles/model.ts` 的 StyleRegistry。

验收输入在 `resources/mmd-input/`，由 `tests/spec.test.ts` 驱动，9 个样本逐条断言
`docs/VSDX解压结构研究/` 的准则，不做旧产物比对；产物 `resources/vsdx-output/`
本地产出、可再生成，不入验收契约。
