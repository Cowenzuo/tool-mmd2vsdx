# 03 对齐准则与取舍

> 后续任何"对齐官方模板"的工作都按这些准则走；取舍是当前仍然成立的；
> 待核条目是还没取证的。踩坑细节在 `docs/VSDX处理经验/02-坑位与解法.md`，
> 实例代数在各渲染器的文件头注释里。

## 一、五条准则

1. **唯一事实源**：官方模板解压包。母版内容、目录条目、页面实例模式、Connects、
   rels 都以它为准，逐字节可 diff；
2. **零自定义规避**：不自造公式与结构，不用非官方形状顶替缺失的母版。
   母版行为（公式、1-D 行为组、文本四件套）不下放实例，但**官方保存态自带的缓存要照抄**：
   节点实例的 `Geometry`/`Connection` 是带 `F='Inh'` 的缓存，公式仍在母版，
   写实只是把缓存随包发出去。空壳形态会让 OLE 激活首帧按母版默认尺寸作画，
   见 `docs/VSDX处理经验/02-坑位与解法.md` 8.1；
3. **未覆盖即显式暴露**：模板没涵盖的语义显式报不支持或列入待核，不用自定义
   方案填坑；
4. **母版化是唯一验收路径**：spec 强制母版引用角色齐全；自足式分支只作目录缺失时
   的防御兜底，不构成通过路径；
5. **实例模式等于官方保存态**：实例怎么写照抄对应素材样本，不自行发挥。
   样本实例本身带段（实测 `basic-5` 3 段 `Geometry` 加 2 段 `Connection`、
   `class-all-in-one` 56 加 19），"只写若干 XForm 单元格的空壳"不是样本形态。

## 二、仍成立的取舍

| 项 | 取舍 | 说明 |
| --- | --- | --- |
| 文本度量缓存 | 按字符数估算，Visio 打开后按公式重算修正 | 字体度量离线不可复现 |
| 关系线端式与方向 | 统一双端 PAR 钉接、统一"下到上"端口 | 取官方已验证的模式之一，重算收敛 |
| ER 关系名 | 走一维线的文本 | 官方实例里没有关系名行 |
| class 构造型 | 只有 interface 有官方母版 | 其余标记按普通类盒渲染并告警 |
| 母版程序化 | class、ER、sequence 用各自官方模板包内容逐字固化；flowchart 与 block 用 basic 家族 5 种节点加 Dynamic connector | 官方模具不入库、可移植、可 diff |
| 画布尺寸 | 页面等于内容外包围框加两倍半线宽，全图型 `DrawingResizeType=2` | Visio 默认会按打印纸倍数放大页面并平移图形 |
| 实例几何写实 | 节点实例自带 `Geometry`/`Connection`，照抄 Visio 保存态：`V` 值加 `F='Inh'`，连接点只写 `X/Y` | OLE 就地激活首帧不解析母版继承，空壳会被按母版默认尺寸（40×30mm）作画，重绘一次才恢复 |
| 消息文本 | 金标准消息带文本，已包含 | 修复了转义层的双重转义问题 |

## 三、仍待核

- sequence 生命线的行距语义：实例缓存形态与官方样本一致，母版公式的语义未取证；
- class 构造型标记与 ER 关系名的官方覆盖范围，素材扩充时复核。

历次对齐 basic-5 与 basic-6 基准的修正都已沉淀进 spec 断言：双端 WALKGLUE 参数镜像、
`WalkPreference=3`、`ConFixedCode=6`、Connects 本体粘附、实例化几何的 L 型两段、
文本柄取弧长中点、路由样式 `ShapeRouteStyle=5`。
