# 03 整改结论（母版化）

> 母版化整改已完成，本文只留现在还有用的东西：整改准则、仍成立的取舍、
> 仍待核的条目。实例代数与踩坑细节在 `docs/VSDX处理经验/02-坑位与解法.md`
> 和各渲染器的文件头注释里，过程记录随 git 历史保留。

## 一、整改准则

后续任何"对齐官方模板"的工作都按这五条走：

1. **唯一事实源**：官方模板解压包。母版内容、目录条目、页面实例模式、
   Connects、rels 都以它为准，逐字节可 diff；
2. **零自定义规避**：不自造公式与结构，不把母版行为下放实例，
   不用非官方形状顶替缺失的母版；
3. **未覆盖即显式暴露**：模板没涵盖的语义显式报不支持或列入待核，
   不用自定义方案填坑；
4. **母版化是唯一验收路径**：spec 强制母版引用角色齐全；自足式分支只作
   目录缺失时的防御兜底，不构成通过路径；
5. **实例模式等于官方保存态**：实例怎么写照抄对应素材样本，不自行发挥。

## 二、整改做了什么

class、ER、sequence 三个专用图型从自绘自足式改为**官方母版实例**：
渲染器写最小差异实例，`Master` 引用加覆盖 cell，行为公式由母版承载；
公用库按 NameU 打包母版三件套，ID 从 100 起；官方 MasterContents 原文
固化成 TS 模板，class 18 枚、er 5 枚、sequence 14 枚，flowchart 与 block
沿用 basic 家族的 6 枚。官方模具不入库。

## 三、仍成立的取舍

| 项 | 取舍 | 说明 |
| --- | --- | --- |
| 文本度量缓存 | 按字符数估算，Visio 打开后按公式重算修正 | 字体度量离线不可复现 |
| 关系线端式与方向 | 统一双端 PAR 钉接、统一"下到上"端口 | 取官方已验证的模式之一，重算收敛 |
| ER 关系名 | 走一维线的文本 | 官方实例里没有关系名行 |
| class 构造型 | 只有 interface 有官方母版 | 其余标记按普通类盒渲染并告警 |

## 四、仍待核

- sequence 生命线的行距语义：实例缓存形态与官方样本一致，
  母版公式的语义未取证；
- class 构造型标记与 ER 关系名的官方覆盖范围，素材扩充时复核。
